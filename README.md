This project is designed as a personal music player.

Uploaded music, playlist covers, and playlist videos should be stored locally unless the project is specifically configured for external storage.

1. Open the project

Open the project folder:

My Music Player/
2. Install backend dependencies

Open a terminal inside the backend folder:

cd backend

Then install the required packages:

npm install
3. Start the server

Run:

node server.js

The Express server should start and serve the application.
